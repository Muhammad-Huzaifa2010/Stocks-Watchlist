# Stocks Watchlist

A full-stack stock watchlist application built with FastAPI, React, PostgreSQL, SQLAlchemy, and JWT authentication.

## Features

- User signup and login
- JWT authentication
- Secure password hashing
- Protected routes
- Create, read, update, and delete stocks
- User-specific watchlists
- PostgreSQL database
- React frontend
- FastAPI backend

## Tech Stack

### Backend
- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- JWT
- bcrypt

### Frontend
- React
- Vite
- JavaScript

## Testing

Backend tests are written with pytest.
